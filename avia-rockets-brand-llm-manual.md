**Versión:** 1.0  
**Uso:** Repositorio GitHub / instrucciones para agentes LLM / diseño web / producto / comunicaciones  
**Marca:** AVIA ROCKETS  
**Sistema visual base:** Arc Board 10F  
**Última actualización:** 2026-05-22

---

## 1. Propósito del documento

Este manual define cómo debe comportarse un LLM cuando cree, edite o evalúe cualquier pieza relacionada con **AVIA ROCKETS**: sitio web, dashboards, emails, pitch decks, UI, app móvil, documentación, prompts de diseño, contenidos comerciales y material de marca.

La función principal es mantener integridad visual, verbal y estratégica.  
El LLM no debe “inventar una marca nueva”. Debe trabajar dentro de este sistema.

---

## 2. Fuentes internas usadas para este manual

Este manual se construye a partir de los boards visuales provistos por AVIA ROCKETS:

1. **Arc Board 10F — Concept / Visual System / Logo / Color / Typography.**

## 3. Identidad central

AVIA ROCKETS es una marca de infraestructura, automatización, datos e integración para equipos modernos.

La marca debe comunicar:

- Velocidad controlada.
- Infraestructura confiable.
- Automatización operacional.
- Inteligencia aplicada.
- Producto SaaS moderno.
- Claridad ejecutiva.
- Tecnología con ambición, pero sin estética infantil de “cohete espacial”.

La marca **no** debe parecer:

- Startup genérica sin foco.
- Agencia de marketing.
- Empresa aeroespacial literal.
- Marca gamer.
- Marca cripto.
- Software barato de automatización sin confianza empresarial.

## 4. Frase matriz

La frase matriz permitida es:

> **Build. Connect. Launch.**

Puede traducirse en contextos hispanos como:

> **Construye. Conecta. Lanza.**

Pero la versión principal de marca debe mantenerse en inglés cuando se use como tagline.

## 5. Arquitectura verbal de marca

### 5.1 Tono

El tono debe ser:

- Directo.
- Ejecutivo.
- Técnico, pero entendible.
- Seguro.
- Breve.
- Orientado a acción.
- Más “infraestructura de confianza” que “marketing inspiracional”.

Evitar exageraciones vacías como:

- “Revolucionamos el futuro”.
- “La mejor plataforma del mundo”.
- “Solución mágica”.
- “Transformación digital 360”.
- “IA que lo hace todo”.

### 5.2 Voz

AVIA ROCKETS habla como una plataforma técnica seria que ayuda a moverse rápido sin perder control.

Ejemplo correcto:

> Connect your tools, automate critical workflows, and turn operational data into decisions.

Ejemplo incorrecto:

> We help you skyrocket your business to the moon with amazing AI-powered automations.

La segunda frase es basura para esta marca: suena genérica, infantil y poco confiable.

## 7. Sistema visual

## 7.1 Logo

El logo base combina:

- Un marco blanco incompleto de bordes redondeados.
- Un arco azul ascendente.
- Dos nodos circulares azules.
- Wordmark “AVIA ROCKETS”.
- La letra **R** destacada en azul.

El símbolo representa conexión, trayectoria, aceleración y sistema.  
No debe interpretarse como un cohete literal en la mayoría de las aplicaciones.

### 7.2 Versiones permitidas

Permitidas:

- Logo completo horizontal.
- Icon-only mark.
- App icon cuadrado.
- Favicon simplificado.
- Versión monocromática.
- Versión para bordado.
- Versión blanca sobre fondo navy.
- Versión oscura sobre fondo claro solo cuando la composición lo exija.

No permitidas:

- Cambiar la curva por una flecha.
- Agregar fuego, humo, estrellas decorativas o planetas.
- Usar un cohete caricaturesco.
- Usar degradados complejos en el logo principal.
- Distorsionar el arco.
- Separar nodos y marco como elementos decorativos sin jerarquía.
- Cambiar el azul principal por cyan, morado, verde o rojo.

## 8. Paleta de color

La paleta oficial estimada desde los boards es:

```css
:root {
  --avia-rocket-blue: #0A6CFF;
  --avia-pure-white: #FFFFFF;
  --avia-deep-navy: #071426;
  --avia-slate: #12213A;
  --avia-steel: #8A95A6;
}
```

### 8.1 Uso recomendado

**Deep Navy `#071426`**  
Fondo principal premium. Usar en hero, login, dashboards oscuros, headers y piezas de marca.

**Rocket Blue `#0A6CFF`**  
Color de acción. Usar en CTAs, estados activos, acentos, gráficos principales, nodos del logo y links.

**Pure White `#FFFFFF`**  
Texto principal sobre navy. Fondos limpios en dashboards light y secciones comerciales.

**Slate `#12213A`**  
Superficies secundarias oscuras, cards, sidebars, bordes suaves y contenedores.

**Steel `#8A95A6`**  
Texto secundario, labels, metadatos, líneas divisorias y estados inactivos.

### 8.2 Proporción visual

Usar como regla base:

- 60% Deep Navy o White, según contexto.
- 25% superficies Slate / fondos secundarios.
- 10% texto y grises Steel.
- 5% Rocket Blue.

Rocket Blue debe sentirse preciso, no invasivo. Si todo es azul, la marca pierde jerarquía.

## 9. Tipografía

La tipografía visual de referencia en los boards es un grotesk geométrico tipo **Space Grotesk**.

### 9.1 Stack recomendado para web

```css
font-family: "Space Grotesk", "Inter", "Manrope", system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
```

### 9.2 Jerarquía

Titulares:

- Peso: 600–700.
- Tracking: normal o levemente negativo.
- Estilo: claro, ejecutivo, sin adornos.

Labels técnicos:

- Mayúsculas.
- Letter-spacing alto.
- Color azul o steel.
- Tamaño pequeño.

Cuerpo:

- Peso 400–500.
- Alto de línea generoso.
- Evitar párrafos largos.

### 9.3 Regla para LLM

Cuando el LLM cree UI, debe evitar fuentes “tech futuristas” difíciles de leer. Nada de estilos tipo sci-fi barato. La marca es SaaS premium, no póster de nave espacial.

## 10. UI web

### 10.1 Estilo general

AVIA ROCKETS debe verse como una plataforma SaaS de alto estándar:

- Layout limpio.
- Mucho espacio negativo.
- Dashboards reales o plausibles.
- Cards con bordes suaves.
- Jerarquía clara.
- Dark mode premium.
- Light mode funcional para producto.
- Contraste alto.
- Menús simples.

### 10.2 Componentes recurrentes

Usar:

- Sidebar dark navy.
- Topbar clara o navy.
- Cards blancas sobre dashboard light.
- Cards slate sobre dashboard dark.
- KPIs con variaciones porcentuales.
- Gráficos lineales simples.
- Donuts de health/status.
- Tablas limpias.
- Estados: Active, Paused, Failed, Completed, Warning.
- Botones primarios Rocket Blue.

### 10.3 Componentes prohibidos

Evitar:

- Gradientes excesivos.
- Glassmorphism sin control.
- Neon cyberpunk.
- Cards saturadas.
- Sombras duras.
- Iconos 3D caricaturescos.
- Fondos espaciales con estrellas exageradas.
- Astronautas, planetas o llamas de cohete.

## 14. Dashboard

### 14.1 Métricas permitidas

Ejemplos coherentes con la marca:

- Workflows.
- Executions.
- Success Rate.
- Time Saved.
- Automation Health.
- Revenue Impact.
- Customer Health Score.
- Uptime.
- Response Time.
- Error Rate.
- Recent Alerts.
- Top Integrations.

### 14.2 Estilo de datos

Los datos pueden ser demo, pero deben parecer realistas.  
No usar números absurdos como “999999% growth” o “AI saves 10,000 hours instantly”.

Correcto:

```text
Success Rate: 99.6%
Time Saved: 320h
MRR: $482k
Uptime: 99.98%
```

Incorrecto:

```text
Revenue Growth: 9000%
AI Magic Score: 100000
```

## 15. Iconografía

### 15.1 Estilo

Iconos:

- Lineales.
- Geométricos.
- Simples.
- De 1.5px a 2px de grosor.
- Preferentemente blancos, steel o rocket blue.
- Sin rellenos innecesarios.

### 15.2 App icon

El app icon debe usar:

- Fondo navy.
- Símbolo Arc Board 10F.
- Bordes redondeados.
- Alto contraste.
- Versión simplificada para tamaños pequeños.

### 15.3 Favicon

Para 32x32 px:

- Usar solo el icon mark.
- Reducir detalles.
- Mantener arco y nodos.
- Evitar wordmark.
- Fondo navy.

---

## 16. Bordado y aplicaciones físicas

Para bordado 3D:

- Usar el icon-only mark o logo horizontal simplificado.
- Mantener trazos gruesos.
- Evitar detalles finos.
- No usar degradados.
- Usar navy como base.
- Usar blanco y azul como hilos principales.
- Aumentar separación entre elementos si el tamaño es pequeño.
- No bordar textos demasiado chicos.

En gorros navy:

- Logo blanco + azul.
- Wordmark opcional solo si el ancho lo permite.
- Preferir versión horizontal.
- Evitar claims pequeños debajo del logo.

## 20. Prompts base para generación visual

### 20.1 Prompt general para web

```text
Create a premium SaaS website for AVIA ROCKETS, a modern automation, integration, and operational intelligence platform. Use a deep navy and pure white visual system with electric rocket blue accents. The logo uses a rounded square frame with a rising blue arc and two blue nodes. The style must feel executive, technical, clean, scalable, and trustworthy. Include realistic dashboards, workflow metrics, integrations, KPI cards, and clear CTAs. Avoid childish space imagery, rockets, planets, neon cyberpunk, crypto aesthetics, and excessive gradients.
```

### 20.2 Prompt para dashboard

```text
Design a dark premium executive dashboard for AVIA ROCKETS. Include workflow runs, success rate, automation health, revenue impact, customer health, infrastructure status, alerts, integrations, and recent activity. Use deep navy backgrounds, slate cards, white typography, steel secondary text, and rocket blue highlights. The UI should be clean, dense but readable, enterprise-ready, and visually aligned with modern SaaS products.
```

### 20.3 Prompt para app móvil

```text
Design a mobile founder control panel for AVIA ROCKETS. Focus on executive overview, workflow alerts, daily reports, integrations, approvals, revenue pulse, and customer notifications. Use a dark navy premium interface with rocket blue active states and clear KPI cards. The experience must feel fast, controlled, and useful for founders managing operations on the move.
```

### 20.4 Prompt para bordado

```text
Create an embroidery-friendly version of the AVIA ROCKETS logo for a navy cap. Use a simplified horizontal layout with thick white strokes for the frame, thick rocket blue arc and nodes, and a clean wordmark only if legible. Avoid gradients, thin lines, small details, shadows, and complex textures. The design must work as 3D puff embroidery.
```

```css
  --avia-border-dark: rgba(255, 255, 255, 0.10);
  --avia-border-light: rgba(7, 20, 38, 0.10);
```

```js

  extend: {

      avia: {

        steel: "#8A95A6",
```

### 21.3 Botones

Primario:

- Fondo Rocket Blue.
- Texto blanco.
- Borde sutil o sin borde.
- Radio 12–16px.
- Hover más oscuro, no más brillante.

Secundario:

- Transparente o navy.
- Borde steel/navy con opacidad.
- Texto blanco en dark mode o navy en light mode.

### 21.4 Cards

Dark mode:

```css
background: #12213A;
border: 1px solid rgba(255,255,255,0.10);
border-radius: 18px;
```

Light mode:

```css
background: #FFFFFF;
border: 1px solid rgba(7,20,38,0.10);
border-radius: 18px;
```

## 22. Checklist para cualquier entrega del LLM

Antes de entregar una pieza AVIA ROCKETS, el LLM debe verificar:

- ¿Usa la paleta oficial?
- ¿Respeta el logo Arc Board 10F?
- ¿Evita metáforas espaciales infantiles?
- ¿Se entiende qué vende AVIA ROCKETS?
- ¿La UI parece SaaS premium?
- ¿Los textos son breves y concretos?
- ¿Los dashboards tienen datos plausibles?
- ¿El azul se usa como acento, no como ruido?
- ¿La composición tiene suficiente aire?
- ¿Funciona en dark y light mode?
- ¿El resultado podría verse bien en web, email y producto?
- ¿La pieza sirve para Avia OPS, Avia Intelligence, Avia Labs o la plataforma general?

Si falla en más de dos puntos, la propuesta debe corregirse antes de mostrarse.

## 23. Criterio de rechazo

El LLM debe rechazar o rehacer propuestas que:

- Cambien el logo sin necesidad.
- Usen estética de cohete caricaturesco.
- Parezcan plantillas genéricas de SaaS.
- No tengan jerarquía visual.
- Usen colores fuera de sistema.
- No distingan producto, marca y comunicación.
- Usen copy inflado sin contenido.
- Hagan que AVIA ROCKETS parezca una agencia cualquiera.

## 26. Resumen ejecutivo

AVIA ROCKETS debe verse y sonar como una plataforma SaaS premium para automatización, integración e inteligencia operacional.  
La marca tiene una identidad fuerte: navy profundo, blanco, azul eléctrico, logo Arc Board 10F, dashboards limpios y lenguaje ejecutivo.  
El mayor riesgo es caer en clichés de cohetes, IA genérica o estética de startup barata.  
La regla central es simple:

> **Build. Connect. Launch.**  
> Sin humo. Sin caricatura. Con control, datos y ejecución.
